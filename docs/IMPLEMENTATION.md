# 구현 범위와 설계 대비 차이

이 커밋은 설계 문서를 실행 코드로 옮긴 초기 버전입니다. 66개 설계 API 경로를 모두 등록했지만 모든 필드·선택 기능이 설계서와 완전히 동일하다는 의미는 아닙니다. 실제 입력 계약은 `/openapi.json`과 `app/contracts.py`, 응답은 구현 코드와 통합 테스트가 기준입니다.

|영역|실행 가능한 기능|초기 버전의 제한|
|---|---|---|
|독자 화면|홈·기사·내 지역·지역 비교·팩트체크·근거·방법·파일·정정|지도와 통합 기사 검색 UI는 후속 확장|
|데이터|CSV 업로드·원본 해시·지역 매핑·관측·공통 집합·품질·고정|통일 코드 직접 대응; 경계 변경 합산은 수작업 정제 후 CSV로 반영|
|버전 생성|비어 있는 새 DRAFT 생성과 재가져오기|base_dataset_id 복제는 422로 명시적 미지원|
|분석|Decimal 투표율·증감·전국 차이·반복 저참여·표준편차·P90−P10·최고최저 격차·하락 수|builtin-v1, 세 선거·전체 지표 고정 실행|
|도표|분석 결과 연결·불변 도표 버전·SVG 추이와 표|복잡한 시각화 편집기는 없음|
|근거|UTF-8 TXT/MD/CSV 추출, 원문 위치, 키워드 검색|PDF/DOCX/OCR 문헌 추출·의미 검색·벡터 인덱스는 미연동|
|초안|고정 분석 결과 5건에서 근거 연결 초안 생성|생성형 모델을 호출하지 않는 템플릿 방식. 제공한 문헌 ID는 존재 확인만 하며 초안 본문 생성에는 사용하지 않음|
|기사|구조화 본문·Unicode 위치·주장·근거 XOR·개정본·검사|자동 초안은 새 기사로 시작. 기존 개정본 수정 저장은 API로 지원|
|자동 검사|숫자·연도·문장 위치·근거·%/%p의 결정적 검사|모든 자연어 주장·날짜 표현·기관명 의미를 자동 판정하지 않음. 사람 검토 필수|
|팩트체크|FC01~FC20 검증본·판정·작성자와 다른 승인|대체 대상 변경은 별도 변경 관리로 수행|
|공개|기사·분석·FC20개·파일 검수·독립 묶음 승인·원자 공개·철회|리포트·뉴스저널은 업로드 제공. 완성 기사에서 자동 조판하는 편집기는 없음|
|다운로드|PUBLIC·게시 상태 확인 후 파일 바이트 반환|명세의 302 서명 URL 대신 200 파일 응답; 내부 URI 미노출|
|인증|서버가 발급하는 랜덤 12시간 Bearer 토큰, 해시 저장·역할·자기 승인 금지|외부 OIDC·SSO·자동 갱신은 미연동|
|운영|Worker·임대·멱등·오류·감사·Docker Compose·CI|운영 TLS·모니터링 수집기·HA·클라우드 백업은 배포 전 구성|

## 호환 차이

- 공개 비교는 `data` 배열과 공통 `page`를 반환하며 각 행에 지표·범위를 포함합니다. 설계서의 `data.rows` 객체와 다릅니다.
- 공개 파일 목록은 `handover_file_id`, 홈 context는 `run_ids`를 제공합니다. 전체 DTO의 필드 이름은 실제 OpenAPI·코드를 확인하세요.
- 원본 등록은 수집 시각을 서버에서 기록합니다. 문헌 입력은 UTF-8 CSV/TXT/MD로 제한합니다.
- 근거 검색은 source_ids 필터와 키워드를 지원합니다. 연도·지역 필터는 조용히 무시하지 않고 422로 알립니다.
- 역할 API는 서버에서 확인하지만 프론트엔드는 메뉴 전체를 보여주고 권한 없는 실행은 403으로 안내합니다.
- 브라우저는 새로고침 시 토큰을 잊습니다. 토큰 저장소·쿠키·localStorage에 인증정보를 보관하지 않습니다.
- 요청 제한은 프로세스 메모리 기준입니다. 멀티 인스턴스 운영에서는 진입 계층의 공유 제한을 별도 적용해야 합니다.
- API 스키마 `v1`은 이 초기 구현의 계약입니다. 엄격한 원 설계 DTO로 전환할 때는 이 문서와 계약 시험을 먼저 갱신해야 합니다.

## 실제 선거 데이터 주의

샘플 CSV의 지역·수치·전국 합계·기사·팩트체크는 시연용 가상 자료입니다. 데모 생성은 서로 다른 가상 사용자 역할의 승인 기록을 명시적으로 추가합니다. 실제 선거 사실을 확인한 기록이나 운영 승인을 뜻하지 않습니다. `demo`는 데이터가 없는 DB에서만 실행하며 실제 프로젝트 DB와 분리해야 합니다.
